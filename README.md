# WinUbuntu 24.04 LTS (Minimal Netinstall)

Минимальный, легковесный и визуально дружелюбный дистрибутив на базе **Ubuntu 24.04 LTS (Noble Numbat)** для слабых ПК и старых ноутбуков (класса Intel Celeron J1800 / 2–4 ГБ ОЗУ).

---

## 🎯 Главная идея и концепция

- **«Linux для домохозяек»**: интерфейс полностью повторяет привычную логику Windows 10/11 (кнопка «Пуск» с поиском в левом нижнем углу, нижняя панель задач, иконки приложений, трей с часами и громкостью справа, значок «Свернуть все окна»).
- **Минимальный вес ISO**: образ весит всего ~700 МБ. Он содержит только ядро, сетевые драйверы и интуитивный графический установщик **Calamares**.
- **Сетевая догрузка (Netinstall)**: все пользовательские приложения скачиваются из сети прямо во время установки.
- **Работа из коробки**: без консоли, без танцев с бубном.

---

## 🖥️ Предустановленный набор приложений

Все программы подобраны по принципу максимальной простоты, скорости и единого лаконичного стиля:

| Назначение | Программа | Почему выбрана |
|---|---|---|
| **Веб-браузер** | **Яндекс.Браузер** (Stable) | Официальный deb-репозиторий Яндекса с автообновлением. Привычен пользователям, встроенный перевод видео и синхронизация. |
| **Видеоплеер** | **Celluloid** (MPV GUI) | Минималистичный плеер без визуального мусора с аппаратным ускорением Intel VA-API для плавного воспроизведения HD/FullHD на Celeron. |
| **Аудиоплеер** | **Audacious** | Простой плеер без перегруженных библиотек, мгновенный запуск, список треков. |
| **Просмотр фото** | **Eye of GNOME (eog)** | Классический просмотрщик: листание стрелками, зум колёсиком мыши, полноэкранный режим. |
| **Архиватор** | **File-Roller** | Графический интерфейс как у WinRAR / 7-Zip, поддержка `.zip`, `.rar`, `.7z`, контекстное меню «Распаковать сюда». |
| **Документы / PDF** | **Atril** | Быстрый и лёгкий просмотр PDF и документов. |
| **Оптимизация ОЗУ** | **zram-tools** | Сжатый swap в оперативной памяти (zstd), спасает от зависаний при открытии многих вкладок браузера на 4 ГБ ОЗУ. |

## ⌨️ Привычные горячие клавиши Windows

- `Win` (Super) — открыть меню «Пуск»
- `Win + E` — открыть файловый менеджер («Этот компьютер»)
- `Win + D` — свернуть все окна / показать рабочий стол
- `Alt + Tab` — переключение между открытыми окнами
- `Ctrl + Shift + Esc` — диспетчер задач
- `PrintScreen` — снимок экрана
- `Win + Стрелки` — прикрепление окна к левой/правой половине экрана

## 🚀 Как собрать образ через GitHub Actions (Самый простой способ)

Вам **не нужно** устанавливать Linux на свой компьютер, чтобы собрать образ:

1. Создайте пустой репозиторий `WinUbuntu` в своем аккаунте GitHub:
   [https://github.com/new](https://github.com/new)
2. Загрузите код в репозиторий:
   ```bash
   git remote add origin https://github.com/ntvampire/WinUbuntu.git
   git branch -M main
   git push -u origin main
   ```
3. Откройте вкладку **Actions** в репозитории на GitHub.
4. Выберите воркфлоу **Build WinUbuntu ISO** и нажмите кнопку **Run workflow**.
5. Через 10–15 минут GitHub бесплатно соберет ISO-образ и прикрепит его к релизу или артефактам сборки для скачивания!

## 💾 Запись на флешку (Ventoy)

Образ полностью оптимизирован для **Ventoy**:
1. Установите [Ventoy](https://www.ventoy.net/) на вашу USB-флешку.
2. Просто скопируйте файл `winubuntu-24.04-minimal-amd64.iso` на флешку как обычный файл.
3. Перезагрузите компьютер, выберите загрузку с флешки (поддерживаются как старый **Legacy BIOS**, так и современный **UEFI**).

## 💻 Локальная сборка (для Ubuntu / Debian / WSL2)

Если у вас есть установленная Ubuntu или WSL2:
```bash
sudo ./build.sh
```
Готовый ISO-образ появится в папке `output/`.

## 📋 Минимальные системные требования

- **Процессор**: 64-битный x86_64 (Intel Celeron J1800 / N2840 / Core 2 Duo или новее)
- **Оперативная память**: от 2 ГБ (рекомендуется 4 ГБ)
- **Диск**: от 16 ГБ свободного места
- **Интернет**: проводной Ethernet или Wi-Fi (для загрузки приложений во время установки)
